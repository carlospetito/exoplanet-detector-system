# Sprint 2 – Estudo dos TCEs (Threshold Crossing Events)

Os TCEs são eventos detectados automaticamente pelo Kepler Pipeline quando a queda de brilho de uma estrela ultrapassa um limite estatístico ("Threshold").

Estes eventos não são exoplanetas confirmados, mas sim candidatos.  
A tabela contém:

- Período orbital estimado
- Época do trânsito
- Duração estimada do trânsito
- Profundidade da queda no fluxo
- SNR do evento
- Disposição automática (CANDIDATE, FALSE POSITIVE, UNKNOWN)

O TCE é útil como ponto inicial para análise, pois representa onde o Kepler acredita ter havido um trânsito.  
Isso permite comparar os resultados do BLS com os valores fornecidos pelo catálogo da NASA.
